# Portal 产品需求文档

版本：v0.7 · 连续移动速度 · 2026-09-06

## 产品目标

Portal 让被信息打扰的人，借助手边的手机获得片刻安静。打开一个治愈的环境，轻轻转动手机或移动头部，感到自己置身其中。无声音、账号、后台服务、打卡、使用时长激励或健康收益承诺。

环境不局限于远景与旷野。有猫的温暖居家环境、温馨小店等近景也是创作方向。当前「星海浅眠」与「清晨湖畔」保留作为方向探索，本轮不更换或修复图片。

## 当前体验

- 默认「星海浅眠」。首屏展示 Portal、“给自己片刻，去别处。”、“打开这扇窗”和“先随便看看”。
- “打开这扇窗”申请手机姿态与前摄权限，入口说明摄像头仅在本机估计眼位，不录制、不上传。“先随便看看”无需权限即可拖动浏览。
- 画面采用固定视场角，不提供缩放选择；授权、模型加载和追踪距离变化不引起自动缩放。
- 手机俯仰与倾斜以重力方向为准。平放进入后拿到竖直位置，应看向地平线。首次对齐和回正只改变水平朝向，不将初始持机姿势视为“直立”。
- 眼位以正对屏幕的稳定采样为中心，增强左右、上下位移响应；只要位置有效，即使大幅偏离中心也继续参与计算，不因大幅侧移重新要求稳定采样；本轮不启用前后移动导致的缩放。设置中可独立开关追踪或重新采样，关闭眼位不关闭手机跟随。
- 模型加载时仍可浏览。眼位通过位置和移动速度的连续过渡减少逐帧顿挫，不因移动幅度大而忽略有效位置；丢失后保持最后显示位置，不自动回中；重新发现时沿用原中心平滑恢复。
- “随手机”开启期间禁用拖动和方向键转向，轻触仍可唤出工具栏；关闭后恢复手动浏览。姿态权限拒绝时保留拖动降级。
- 轻触唤出环境、随手机、设置、回正、退出。4 秒无操作隐藏，面板打开期间保持可操作。
- 回正清除拖动偏移并重置水平朝向；切换环境朝向新环境的初始水平方向。
- 后台停止渲染、摄像头和姿态监听；回到页面后轻触恢复，重新采样眼位。退出释放资源并返回首页。

## 降级、隐私与边界

姿态拒绝时仍可拖动；摄像头拒绝、模型加载或运行失败时仍保留拖动和可用姿态。只有摄像头可用时仍支持眼位响应。视频默认不可见，仅用于本机单张人脸推理，不录制、不上传、不持久化。无麦克风、埋点、广告或账户服务，不保存眼位基准。

普通前摄的眼位与距离估计是单目近似，不承诺测量精度。普通屏幕提供一张画面，双眼中点是折中观察点。全景视为无限远，不提供近远景视差、遮挡后内容或双眼立体画面。固定投影加局部眼位偏移是体验近似，不是物理尺寸标定的完整离轴窗口。

两张 PNG 是全景原型，不是真正 HDR。素材清晰度、接缝及极点失真需后续处理。

## 沉浸与平台

全站禁止文字长按选择、长按上下文菜单和原生图片拖拽，保留按钮点击、面板滚动及手动浏览时的全景拖动。

iPhone Safari 优先，桌面可调试，Android Chrome 基础兼容。画布覆盖可用视口，适配横竖屏、动态地址栏与安全区域。界面采用中文低对比柔光面板。

Safari 标签页的系统状态栏与地址栏无法由网页强制移除。普通标签页的背景和主题色随环境变化；主屏幕模式使用中性深色作为系统保留区域及启动背景，避免紫色条带，支持添加到主屏幕后独立打开；全屏 API 可用时显示全屏按钮。系统决定状态栏呈现，不提供离线缓存。

## 验收标准

- 平放进入、拿起、回正、横竖屏和恢复后重力方向正确；静止不漂移，旋转不过度抖动。
- 固定投影不受旧视野、距离设置或权限状态影响。
- 眼位稳定采样、大幅左右上下响应、无效数值拒绝、丢失保持、关闭和重新采样可用。
- 权限拒绝、模型失败、退出时延迟返回的权限结果不影响继续浏览，也不泄漏媒体资源。
- 后台与退出释放摄像头和传感器；推理只处理最新帧，不积压。
- 设置中提供可展开的本机性能数据，辅助用户反馈卡顿，不在沉浸画面持续显示。
- 渲染争取 60 fps，最低目标 30 fps，性能不足降低像素比与推理频率。
- 通过代码、几何与浏览器流程测试。真实 iPhone 的跟随感、系统栏和持续性能由用户测试反馈，不用模拟事件或合成视频冒充真机验收。
