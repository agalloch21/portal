# Portal 产品需求文档

版本：v0.9 · 全景与空间微动 · 2026-09-06

## 产品目标

Portal 让被信息打扰的人，借助手边的手机获得片刻安静。主推工作时将手机横向固定在显示器下方，疲惫时低头看一眼安静的环境；眼位随自然头部移动轻柔响应，不要求刻意摇头或转动手机。无声音、账号、后台服务、打卡、使用时长激励或健康收益承诺。

环境不局限于远景与旷野。有猫的温暖居家环境、温馨小店等近景也是创作方向。保留星海与花房方向，将湖畔升级为高分辨率摄影全景，采用全景背景叠加少量空间动态元素。

## 当前体验

- 首页固定「星海浅眠」，退出沉浸也返回星海；环境链接在进入沉浸后生效。首屏展示 Portal、“给自己片刻，去别处。”、“打开这扇窗”和“先随便看看”。
- “打开这扇窗”每次进入均默认开启眼位追踪并申请手机姿态与前摄权限，入口说明摄像头仅在本机估计眼位，不录制、不上传。“先随便看看”无需权限即可拖动浏览。
- 居中视场角保持默认值，不提供焦距缩放选择；眼位默认 1 倍，可在设置中调整至 0.5–3 倍并恢复默认，仅本机保存。侧移采用离轴投影，边缘视角随位置自然变化。
- 手机倾斜产生的摄像头眼位变化不能被重复放大成反向头部移动。手机俯仰与倾斜以重力方向为准。平放进入后拿到竖直位置，应看向地平线。首次对齐和回正只改变水平朝向，不将初始持机姿势视为“直立”。
- 眼位以正对屏幕的稳定采样为中心，默认不夸大左右、上下位移响应；只要位置有效，即使大幅偏离中心也继续参与计算，不因大幅侧移重新要求稳定采样；本轮不启用前后移动导致的缩放。设置中可独立开关追踪或重新采样，关闭眼位不关闭手机跟随。
- 模型加载时仍可浏览。眼位优先保持平滑，接受适量跟随延迟，通过位置和移动速度的连续过渡减少逐帧顿挫，不因移动幅度大而忽略有效位置；丢失后保持最后显示位置，不自动回中；重新发现时沿用原中心平滑恢复。
- “随手机”开启期间禁用拖动和方向键转向，轻触仍可唤出工具栏；关闭后恢复手动浏览。姿态权限拒绝时保留拖动降级。
- 轻触唤出环境、随手机、设置、回正、退出。4 秒无操作隐藏，面板打开期间保持可操作。
- 回正清除拖动偏移并重置水平朝向；切换环境朝向新环境的初始水平方向。
- 后台停止渲染、摄像头和姿态监听；回到页面后轻触恢复，重新采样眼位。退出释放资源并返回首页。

## 场景方向

环境顺序：星海浅眠、浅蓝之下、星云缓行、星间花房、林间微光、清晨湖畔、静谧海湾。午后小院和海风露台不再提供。前四个梦境场景在初始视野有适量可见动态，同时保留周围空间的元素。

采用静态高质量全景背景与少量动态三维元素，不再提供独立三维庭院、回廊或树屋模型环境。新增适合安静停留的水下、森林和太空环境，保留花房与早期全景对照。手机初始视角保持自然观看高度，近物不挤满画面。

动态元素服从场景空间与手机朝向：星海漂浮微光、水下微粒与气泡及柔和光束、星云环游星尘、花房飘落花瓣、林间微光、星空中的星点与偶发流星。运动缓慢、数量克制，无声音、强闪烁、计时任务或激励。可单独关闭环境微动，初始尊重系统减少动态效果。

居中时短边视场角为 60°；手机改变朝向，眼位横向位移改变非对称视锥，不以额外旋转代替离轴投影。眼位追踪继续保留稳定采样、平滑与丢失保持。此模式是全景浏览体验，不声称是具有真实深度的物理窗口。

优先使用原生高分辨率素材，实际像素尺寸和来源必须记录；不把普通放大称为新增真实细节。生成素材与摄影 HDRI 区分标记。菜单仅需支持切换，方向确定后再打磨界面。

## 降级、隐私与边界

姿态拒绝时仍可拖动；摄像头拒绝、模型加载或运行失败时仍保留拖动和可用姿态。只有摄像头可用时仍支持眼位响应。视频默认不可见，仅用于本机单张人脸推理，不录制、不上传、不持久化。无麦克风、埋点、广告或账户服务，不保存眼位基准。

普通前摄的眼位与距离估计是单目近似，不承诺测量精度。普通屏幕提供一张画面，双眼中点是折中观察点。全景视为无限远，不提供近远景视差或遮挡后内容。动态元素具有空间坐标，但背景没有深度图，不能准确遮挡粒子；整体不提供双眼立体显示。当前离轴投影基于虚拟屏幕尺度与采样中心，不是物理尺寸精确标定的窗口。

生成 PNG 属于全景原型，不是真正 HDR。高分辨率摄影全景与生成素材分别标注来源；球面结构、接缝和极点质量受素材限制。

## 沉浸与平台

全站禁止文字长按选择、长按上下文菜单和原生图片拖拽，保留按钮点击、面板滚动及手动浏览时的全景拖动。

iPhone Safari 优先，桌面可调试，Android Chrome 基础兼容。画布覆盖可用视口，适配横竖屏、动态地址栏与安全区域。界面采用中文低对比柔光面板。

Safari 标签页的系统状态栏与地址栏无法由网页强制移除。普通标签页的背景和主题色随环境变化；主屏幕模式使用中性深色作为系统保留区域及启动背景，避免紫色条带，支持添加到主屏幕后独立打开；全屏 API 可用时显示全屏按钮。系统决定状态栏呈现，不提供离线缓存。

## 验收标准

- 全部场景可切换，模型庭院选项移除；失败时保留当前风景，旧异步结果不覆盖新选择。
- 纯手机旋转、眼位移动和组合输入均保持固定短边视场角；平放后拿起保持重力方向。
- 动态元素在世界坐标中跟随观看方向，不作为固定屏幕贴纸；暂停动画不停止眼位和手机输入。
- 大幅眼位有效、丢失保持、重新采样、权限降级以及后台/退出释放行为保留。
- 类型检查、生产构建与针对性测试通过。实际 iPhone 清晰度、跟随感、持续性能由用户测试，模拟结果不冒充真机结论。
