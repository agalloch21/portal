# Portal 产品需求文档

版本：v0.1 · 2026-09-06

## 1. 产品主张

Portal 是一扇通向片刻安静的窗。用户被消息、工作或信息流打扰时，仍能借助手边的手机，暂时把注意力放到一个开阔、柔和、没有任务的环境中。

产品面向希望随时短暂休息的手机用户。目标使用情境是一段不需要准备、不需要完成的休息；用户可以停留几秒，也可以停留几分钟。产品不要求用户描述情绪，不评价休息效果，也不承诺治疗或健康收益。

## 2. 体验原则

- 环境是主体。沉浸时画面覆盖显示区域，操作界面主动退场。
- 进入容易。首次使用可以直接浏览；校准是可选的，不阻止用户进入。
- 窗口随观看位置响应。手机转动时可以看向环境的不同方向；眼睛相对屏幕移动时，透视随之变化。
- 场景安静且可控。采用低刺激的色彩、柔和光线和开阔空间，不主动旋转、推进或震动视角。
- 不增加任务。无打卡、积分、连续使用提醒、倒计时和社交比较。
- 权限不成为门槛。摄像头或姿态不可用时，仍可以拖动欣赏环境。

## 3. 第一版范围

### 环境

| 环境 | 感受 | 默认 |
| --- | --- | --- |
| 星海浅眠 | 淡紫色星海、柔光星球、平静水面，梦境般的轻盈 | 是 |
| 清晨湖畔 | 薄雾、远山、湖水与苔藓，清晨的自然留白 | 否 |

第一版不提供声音、上传自定义环境、场景编辑、账号、云存储、后台服务或公共发布功能。

### 首屏

背景为星海浅眠，展示 Portal、文案“给自己片刻，去别处。”以及两个入口：

- **打开这扇窗：** 进入沉浸体验，申请手机姿态与前置摄像头权限。
- **先随便看看：** 无需上述权限，进入拖动浏览。

摄像头启用前后明确告知：“摄像头仅在本机估计眼位，不录制、不上传。”浏览器自己的权限提示保留。

### 沉浸

全景占满页面显示区域。手机姿态、眼位信息与拖动操作根据可用能力共同控制视图。环境不会自行运动。

轻触画面可以显示或隐藏工具栏。工具栏包含环境选择、眼位追踪开关、校准、方向回正和返回。没有操作时 4 秒后自动隐藏；对话框打开期间保持可操作。支持键盘操作和可见焦点。

环境切换后朝向该环境的初始景观。方向回正清除手动转动偏移，并把当前手机方向作为新的参考。

### 眼位追踪

使用前置摄像头估计一位观看者的双眼中点。摄像头画面不展示在沉浸界面中。追踪准备期间仍能浏览环境；状态以简短文字提示。

短暂失去人脸时保持最后眼位，持续丢失后平滑回到默认观看位置；重新出现时平滑恢复。极端位置与距离不应造成画面翻转或突跳。

眼位开关只控制摄像头追踪，不关闭已经获得的手机姿态能力。完全退出时释放两者。

### 可选校准

默认显示区域短边 64 mm、眼睛到屏幕 350 mm。用户可以输入实际显示区域短边及当前观看距离，正对屏幕停留片刻后保存采样。

没有检测到眼位时仍可保存显示尺度；界面必须说明尚未完成眼位采样。提供恢复默认值。设置只存储在当前设备，不保存照片、视频或面部关键点。

### 暂停与退出

- 切到后台立即停止画面更新，并释放摄像头、追踪任务和姿态监听。
- 回到页面后显示“这扇窗，还在这里。”，轻触继续才恢复所需能力。
- 返回首页释放摄像头与姿态资源；保留本机校准设置。

## 4. 能力降级

| 可用能力 | 体验 |
| --- | --- |
| 姿态 + 眼位 | 手机转动与观看位置同时影响窗口 |
| 仅姿态 | 根据手机方向浏览，采用默认眼位 |
| 仅眼位 | 固定参考朝向，透视随眼位变化，可拖动转向 |
| 两者均不可用 | 拖动浏览，采用适合欣赏的视野 |
| 环境加载失败 | 保留已有画面，提示从环境卡片重试 |
| 追踪模型加载失败 | 停止摄像头，保留浏览与可用姿态能力 |
| 无法使用图形能力 | 显示简短设备兼容提示，不伪装为正常沉浸 |

## 5. 隐私与边界

视频和人脸推理全部在设备上进行；不申请麦克风，不上传、录制或持久化视频，不配置统计、埋点、广告与账户服务。网页会向站点请求静态环境图、代码和模型资源。

眼位来源于普通前置摄像头和近似尺度，不提供测量级精度。显示设备只呈现一张画面，对双眼中点近似正确；单眼观看更符合单视点窗口模型。

全景环境视为无限远。可以改变观看方向，但无法生成真实近远景视差、遮挡后内容或双眼立体画面。生成的全景 PNG 是概念素材，不是真正高动态范围 HDR 资源。

## 6. 质量与验收

- iPhone Safari 为第一优先级，支持竖屏与横屏、安全区域、地址栏变化；页面无意外滚动和被遮挡的主要控件。
- 桌面浏览器可以完成无摄像头浏览、场景切换和校准设置；Android Chrome 提供基础兼容。
- 页面首次进入不自动申请权限；用户拒绝权限后仍能完成浏览。
- 正对屏幕时透视对称；头部侧移、靠近、手机旋转的方向符合窗口几何，不发生镜像或重复旋转。
- 主画面目标 60 fps；真机连续体验 3 分钟，最低目标 30 fps。性能不足时降低渲染分辨率和追踪频率，避免积压视频帧。
- 控件按约定隐藏与唤出；校准可跳过；场景切换和追踪丢失不打断使用。
- 退出和后台状态的摄像头资源确实释放；浏览器权限图标的消退时间由系统决定。
- 球面观看时无明显接缝跳变与极点破洞；生成素材的局部失真允许在原型阶段保留并注明。
- 类型检查、生产构建、几何测试、浏览器流程测试通过。真机姿态、摄像头精度和性能独立验收，不以模拟事件或合成视频代替。
