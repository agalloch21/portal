# Portal

给自己片刻，去别处。

全屏静态全景与少量空间动态元素。手机姿态保留重力方向，前摄在本机估计眼位；也可不授权直接拖动浏览。独立三维庭院、回廊和树屋环境已移除。

主推手机横放在显示器下方的桌边风景，累时低头看一眼。眼位默认 1 倍，设置中可调 0.5–3 倍并在本机保存；使用横向离轴投影，保留居中 60° 与固定观看距离，尚非物理屏幕尺寸精确标定。眼位跟随优先平滑，取消位置预测并接受约 0.2–0.3 秒的滤波过渡；丢失识别仍停在最后显示位置。固定摆放时可关闭“随手机”，只保留眼位追踪。

## 启动

使用 Node.js 22.12+ 或 24+。

```sh
npm ci
npm run dev
```

打开终端显示的 localhost 地址。桌面 localhost 可以申请摄像头；局域网 HTTP 手机地址只能用于无权限浏览。

模型与 WASM 已随项目提供。需要重新准备它们时执行 `npm run assets`；这一步需要访问 Google 官方模型存储。依赖升级后重新运行该命令以同步 WASM。

## 手机 HTTPS 调试

准备匹配电脑局域网 IP/主机名、且已被 iPhone 信任的开发证书。证书及私钥不要提交进仓库。运行：

```sh
PORTAL_HTTPS_KEY=/absolute/path/dev-key.pem PORTAL_HTTPS_CERT=/absolute/path/dev-cert.pem npm run dev
```

电脑和手机连接同一网络，在 iPhone Safari 打开 `https://电脑的局域网IP:5173`。证书域名/IP 必须匹配；对未受信任证书点“继续”不等于建立可用的安全环境。生产测试可使用受信任的 HTTPS 静态托管，但本仓库未自动发布到公网。

## 构建与验证

```sh
npm run build
npm run preview
npm test
```

静态发布目录为 `dist/`，从站点根目录提供即可。浏览器测试先执行构建，再运行：

```sh
npx playwright install chromium
npm run test:e2e
```

如果已经安装 Google Chrome，可以使用 `PORTAL_TEST_CHROME=1 npm run test:e2e`，无需下载 Playwright Chromium。

## 使用

- 全站文字禁止长按选择，并禁用长按菜单与原生图片拖拽；按钮点击、面板滚动和允许的全景拖动仍可用。
- 主屏幕画布以绝对定位铺满 100lvh 的页面容器；用户已在当前 iPhone 上确认底部黑条消失。“设置 → 性能数据”提供屏幕、页面、可见视口和画布边界尺寸，便于检查其他设备。

- “打开这扇窗”启用手机姿态与前摄；“先随便看看”直接拖动浏览。
- 眼位开启后，正对屏幕稍停片刻建立中心，再轻轻左右、上下移动头部。
- “随手机”开启时禁止手指拖动和方向键转向，轻触仍可唤出控件；关闭后恢复手动转向。等待姿态数据时也保持此互斥规则，权限拒绝则恢复拖动。
- 轻触唤出工具栏。“随手机”独立控制姿态，“设置”中可开关眼位、重新采样或进入浏览器支持的全屏。
- “回正”只重设水平朝向并清除拖动偏移，保留手机相对重力的俯仰与倾斜。
- 后台释放摄像头和传感器，返回后轻触恢复并重新采样眼位。
- iPhone Safari 分享菜单选择“添加到主屏幕”，从图标打开可减少浏览器工具栏。普通标签页无法强制隐藏系统栏；没有离线缓存。主屏幕模式的画布采用完整视口高度，根背景、启动背景及系统主题色统一为中性深色，避免紫色露底。若系统仍保留底部手势区域，网页不能保证让画面覆盖它。更新后请先完全关闭主屏幕应用再打开；若启动色仍旧，可移除旧图标后重新添加。

## 视角为什么不会再随眼位“放大”

手机姿态滤波没有改动：俯仰与倾斜保留重力方向，首次对齐和回正只处理水平朝向。平放后拿起仍会回到地平线，不以打开网页时的完整姿势作为零点。

之前把眼位作为离轴投影偏移。焦距虽然固定，但偏得越多，左右边缘的实际夹角越小，而且两边不对称；手机转动也会改变前摄中的眼位，可能一起触发这种观感。

现在保留原先的眼位中心方向响应，将它转成额外的俯仰和水平旋转，再与手机姿态组合。所有像素使用同一个居中的 60° 短边投影，因此手机或眼位只改变观看方向，不再缩小视场。仍使用 3 倍眼位增益、原有平滑与丢失保持；这属于舒适的全景浏览，不宣称具有真实深度的离轴窗口。素材本身的球面失真仍可能存在。

动态点和流星位于三维世界坐标中，与全景使用相同朝向和投影；没有额外的背景 UV 扭曲、全屏缩放或镜头摇摆。背景没有深度图，因此动态元素不能准确被图片中的树木、星球遮挡。

## 验证

按改动范围运行相关检查，不必每次跑全套：

```sh
npm test -- tests/view.test.ts
PORTAL_TEST_CHROME=1 npm run test:e2e -- tests/browser/scenes.spec.ts
```

固定视角测试覆盖手机旋转、大幅眼位与横竖屏。浏览器检查场景切换、暂停、异步加载竞争和接缝采样。动态环境下的姿态像素对比会暂停环境微动。摄像头/姿态管线没有改变，相关 Worker 检查仍可用：

```sh
PORTAL_TEST_DEV=1 PORTAL_TEST_CHROME=1 npm run test:e2e -- --grep 'worker preferred'
```

模型与 WASM 全部本地提供，摄像头不录制、不上传。真机清晰度、跟随感、帧率和温度由用户测试；自动化结果不冒充真机结论。本轮没有自动推送或部署。
